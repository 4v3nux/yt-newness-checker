# 🔵 YouTube Newness Dot Checker

Локальное расширение для Google Chrome, которое позволяет мгновенно находить все подписки на YouTube с новыми видео (синими точками), автоматически разворачивает скрытый список каналов и умеет помечать их как просмотренные (включая синхронизацию с сервером YouTube).

---

## ✨ Возможности

* **Сканирование подписок:** Мгновенно собирает список каналов, у которых появились новые видео или шортсы.
* **Авто-разворачивание:** Сама находит и кликает кнопку «Развернуть» в боковом меню YouTube, чтобы проверить абсолютно все подписки, а не только видимые на экране.
* **Интерактивный список:** Удобное выпадающее окно с названиями каналов и прямыми ссылками на них.
* **Массовое прочтение:** Возможность открыть все каналы в фоновом режиме одним кликом, чтобы «синие точки» пропали (и на уровне аккаунта Google, а не только визуально).
